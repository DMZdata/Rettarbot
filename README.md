# Rettarbot

Kravspesifikasjoner og tekniske standarder for DMZ data.

Grunnprinsippet er ett felles sett med krav for alle prosjekter, uavhengig av teknologistack og deploy-plattform. Test skal være fleksibelt; produksjon skal være kontrollert.

| [Sikkerhet](docs/sikkerhet.md) | Quality Gate i GitHub Actions, Dependabot og Snyk, miljøpolicy for test og prod, deploy |
| [Design](docs/design.md) | Svelte, DigDirs designsystem, tilgjengelighet og personvern |
